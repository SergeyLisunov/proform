## 1. Суть продукта (как уже сформулировано на лендинге)

SPORTEO — платформа управления спортивной подготовкой.
«Весь спортсмен — в одной карточке»: тренер, врач, атлет и руководитель —
в одной системе вокруг единой карточки спортсмена. Предиктивная аналитика
нагрузки предупреждает о травме до того, как атлет «сломается».

Мы НЕ электронный журнал для госспортшкол. Мы инструмент для частного сегмента
(клубы, академии, команды, личные тренеры), который убирает хаос из чатов,
Excel и бумажных медкарт.

Стек: Next.js 14, TypeScript, Tailwind, Supabase (SSR + RLS), Vercel.
Архитектура: мультитенантная (организация как пространство).

## 2. Роли (5)

1. athlete (атлет/спортсмен) — в центре. Взрослый с личным тренером ИЛИ
   ребёнок (тогда наблюдатель/плательщик — родитель).
2. coach (тренер) — планирует нагрузку, видит прогресс и «светофор допуска»
   от врача; получает назначения врача к следующей тренировке.
3. doctor (врач) — медкарта, травмы, допуск к нагрузке, восстановление.
   Ключевой дифференциатор.
4. organization (организация/руководитель) — ЗОНТИЧНАЯ роль для частных
   клубов/академий/команд. Объединяет тренеров, врачей и атлетов; управляет
   составом, доступами, расписанием, оплатами; видит агрегаты, а не диагнозы.
5. admin — администрирование платформы.

Принцип: каждый видит ровно то, что нужно ему — по ролям и без утечек
(это уже заявлено на лендинге как «мультиролевая координация»).

Модель организации (для архитектуры):
- Организация = тенант. Внутрь добавляются тренер, врач, атлет.
- Один человек — несколько организаций с разными ролями.
- Два входа атлета: через организацию (клуб приглашает) и B2C (личный тренер).

## 3. Целевые сегменты

P1 — Частные клубы/академии/команды (B2B, роль organization). На лендинге
     основной CTA: «Подключить клуб бесплатно», «аудит клуба за 5 минут».
P2 — Атлет + личный тренер (B2C). Зрелый денежный сегмент.
P3 — Детский спорт + родитель (B2C2P).

НЕ обслуживаем: госспортшколы, ГИС «Спорт», разряды, госотчётность («Мой спорт»).

---

## 4. Дифференциатор №1 — предиктивная аналитика и врач

Уже заявлено и должно быть доведено до уровня «лучших в нише»:
- Автоматический расчёт нагрузки ACWR + ML-модель риска травм →
  предупреждение о перетренированности заранее.
- Связка врач↔тренер: назначения врача тренер видит на следующей тренировке;
  тренер видит «светофор допуска» (light/medium/full/запрет), а не диагнозы.
- Результат для клиента: меньше травм и перетренированности.

Это то, чего нет у «Мой спорт» и у большинства международных коучинг-CRM —
здесь наш ров (moat). Инвестировать сюда в первую очередь по продукту.

## 5. Конкуренты (кратко)

- «Мой спорт» (РФ, госплатформа): бесплатна, ГИС «Спорт», разряды. НЕ конкурируем.
- impulseCRM (РФ): CRM студий (записи/оплаты). Пересечение по монетизации.
- TrueCoach / Trainerize / Everfit / TrainHeroic / Hevy Coach / Virtuagym:
  зрелый сегмент «атлет + тренер». Нельзя быть клоном → ров = врач + ACWR/ML.
- Hexfit: валидирует связку «тренер + медицина».
- SkillShark (оценка), CoachNow (видео) — узкие ниши.

## 6. Сильные стороны (подтверждены на платформе)

- Зрелый продуктовый нарратив и чистый UX (лендинг + онбординг атлета).
- Единая карточка спортсмена (история, медкарта, нагрузки, план — в одном месте).
- Предиктивная аналитика ACWR + ML риск травм (редкая фича на рынке).
- Мультиролевая координация с ролевым доступом без утечек.
- Защита медданных на уровне СУБД (RLS).
- Мультитенантная архитектура под организации — готовая база для B2B.
- AI-инструменты + механика аудита клуба за 5 минут (лид-магнит).

## 7. Слабые стороны / риски

- Нет явного монетизационного слоя в продукте (оплаты/абонементы). РЕШЕНИЕ: P1.
- Сильная международная конкуренция в B2C → держать фокус на рве (врач + ML).
- Доверие к ML-прогнозу: нужны прозрачность модели и понятные пороги.
- БРЕНД-РИСК: имя «Sporteo» уже занято — приложение Sporteo (team management) и
  агентство sporteo Int. Sportmanagement AG (TGI Sport). Риск путаницы/товарного
  знака. ДЕЙСТВИЕ: до вложений в бренд проверить домен sporteo.* и товарные знаки
  в своих юрисдикциях; при конфликте — вариация имени.

## 8. Роадмап (по приоритету)

P1 — Монетизация (организация + тренер): подписка/абонементы, оплаты,
     посещаемость со списанием, напоминания о продлении.
P2 — Связки доступа: organization → coach/doctor/athlete; родитель ↔ ребёнок;
     атлет ↔ личный тренер. Приглашения, роли, права.
P3 — Углубление рва: качество ACWR/ML, объяснимость прогноза, план возврата
     после травмы (совместно тренер+врач), публичная sharing-карточка прогресса.
P4 — Расширение AI-инструментов и автоматизация аудита клуба (лид-генерация).

НЕ делаем: ГИС «Спорт», разряды, госотчётность.

---

## 9. Позиционирование (одной фразой)

«SPORTEO — платформа управления подготовкой для частных клубов, академий, команд
и личных тренеров: тренер, врач, атлет и руководитель в одной системе вокруг
единой карточки спортсмена, с предиктивной аналитикой нагрузки, которая
предупреждает о травме заранее.»

Монетизация: подписка с организации/тренера (не комиссии), вход без банковской
карты, лид-магнит — бесплатный аудит клуба.
