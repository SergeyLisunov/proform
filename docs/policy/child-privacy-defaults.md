# Приватность несовершеннолетних по умолчанию

**Статус:** зафиксировано как P0 стратегического аудита ролей (июнь 2026),
ДО построения социального слоя (лента клуба, реакции, стрики — P1).
Модель-образец: Instagram Teen Accounts (Meta, 2024) — приватность по
умолчанию как лицензия на существование детской платформы, не как фича.

Ребёнок в Sporteo = аккаунт `role='athlete'` со связью в `parent_links`
(см. решение «child = athlete account + parent_links»). Достоверного поля
возраста пока нет — до age-gate (152-ФЗ, открытый вопрос) правила ниже
применяются ко всем аккаунтам с активной parent_link.

## Принципы (обязательны для любого P1+ соц-функционала)

1. **Профиль ребёнка приватен по умолчанию.** Виден только: его тренер
   (trainer_athletes accepted), его клуб (org_members), родитель
   (parent_links), его врач (doctor_athlete connection). Публичный
   passport / поиск — только после явного включения родителем.
2. **Никаких личных сообщений ребёнок ↔ незнакомец.** Direct-чат — только
   внутри care team. Взрослый ↔ чужой ребёнок — только групповые каналы,
   видимые родителям.
3. **Лента клуба — закрытая и конечная.** Тренировки ребёнка видны только
   внутри клуба; никакой бесконечной прокрутки («вы всё посмотрели»);
   никаких рекомендательных алгоритмов.
4. **Никаких публичных метрик популярности ребёнка** (подписчики, счётчики
   лайков). Реакции видны, счётчики-рейтинги по реакциям — нет.
5. **Рейтинги детей — только по усилию и посещаемости**, не по результату.
   Никаких лиг с вылетом, стыдящих уведомлений, streak-guilt механик
   (научно документированный вред подросткам — anxiety-driven retention).
6. **Уведомления ребёнку — только про его тренировочный процесс** (план,
   комментарий тренера, допуск). Никаких re-engagement пушей «вернись».
7. **Родитель управляет настройками** видимости профиля ребёнка и получает
   зеркальные уведомления о значимых событиях (допуск, травма, запись
   тренера) — см. P0 PR-2 (clearance notify) и P1 (недельный отчёт).

## Известные разрывы с текущим кодом (закрывать в P1 до запуска соц-слоя)

- `messages`: поиск собеседника по `is_searchable = true` позволяет чат
  «любой с любым» — для аккаунтов с parent_link нужно сузить до care team
  (нарушает принцип 2).
- `users.profile_public` / `is_searchable` — дефолты не зависят от наличия
  parent_link; при создании ребёнка (register-as-parent, invite child)
  выставлять приватные значения принудительно.
- Публичный passport `/p/[nickname]` — для детей включать только через
  родительский кабинет.

## Что уже соответствует

- `/parent/dashboard` — строгий column allow-list (без HRV/recovery/risk).
- Светофор допуска: родитель read-only через `is_parent_of()` (миграция 092).
- `observation_diary` / `medical_diary` share-флаги — врач/тренер решают,
  что видно; org видит только агрегаты.
