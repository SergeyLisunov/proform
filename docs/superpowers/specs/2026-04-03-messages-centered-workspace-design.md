# Messages Centered Workspace Design

## Goal

Исправить геометрию экрана `messages`, чтобы рабочее пространство сообщений располагалось по центру доступной области, а не визуально уезжало влево внутри широкого shell.

## Scope

- Добавить единый centered content wrapper для экрана `messages`.
- Выровнять hero, KPI-карточки, поиск и список диалогов по одной центральной рабочей колонке.
- Сохранить текущий дизайн карточек, модалок и логику realtime/update/new chat.

## Non-Goals

- Не менять визуальный стиль `messages`.
- Не трогать `ChatModal`, `NewChatModal` и бизнес-логику сообщений.
- Не менять общий layout других экранов.

## Root Cause

Экран `messages` не имеет собственного центрирующего контейнера. Его секции рендерятся с `w-full` прямо внутри широкого shell, поэтому на больших экранах интерфейс занимает все доступное полотно и выглядит смещенным влево.

## UX Direction

Нужен не redesign, а аккуратный workspace-centering pass:

- один общий `max-width` контейнер;
- `mx-auto` для центрального позиционирования;
- одинаковая рабочая ширина у hero, stats, search и списка чатов;
- без изменения текущих визуальных блоков.

## Success Criteria

- `messages` визуально центрируется на desktop.
- Внутренние блоки остаются согласованными по ширине.
- `eslint` и `npm run build` проходят без регрессий.
