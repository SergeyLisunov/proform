# Settings Messages Color Pass Design

## Goal

Сделать верхний блок `settings` цветнее и живее в том же визуальном направлении, что и `messages`, но без возврата к длинному градиентному hero.

## Scope

- Сохранить компактную геометрию верхнего блока `settings`.
- Использовать теплый `messages`-style цветовой язык: мягкий градиент, более выразительные chips, теплый акцент у back-button.
- Не увеличивать типографику и не возвращать второй save CTA.

## Design

- Базовая карточка остается компактной, но получает фон `bg-gradient-to-br from-orange-50 via-background to-background`.
- Back-button получает теплую подложку и более заметный hover в оранжевой палитре.
- Две chips становятся более живыми:
  - первая остается основной оранжевой,
  - вторая остается спокойнее, но с теплым tinted background, чтобы блок читался цельнее.
- Заголовок и подзаголовок сохраняют текущий размер и компактность.
- Текст `completionLabel` остается в header, но получает мягкую tinted surface вместо полностью нейтрального текста.

## Non-Goals

- Не менять layout формы, aside, active section и нижнюю кнопку сохранения.
- Не трогать глобальный `TopBar`.
