# Diary History And Detail Design

## Goal

Усилить athlete-часть `diary` после quick-add pass, чтобы история тренировок читалась как рабочее пространство спортсмена, а не как плоский список записей.

## Scope

- Пересобрать history toolbar над списком тренировок.
- Сгруппировать list-view по времени: `Сегодня`, `Эта неделя`, `Ранее`.
- Усилить list/grid карточки тренировок, сохранив текущую фильтрацию и выбор записи.
- Переработать `ViewEditDrawer` в более сильный athlete detail workspace.
- Подтянуть loading и empty state к уже обновленному визуальному языку `diary`.

## Non-Goals

- Не менять coach-часть `diary`.
- Не переписывать Supabase-схему, `createWorkout`, update/delete flow или sync с `calendar_events`.
- Не выносить drawer/list/card в отдельные файлы в этом проходе.

## UX Direction

Экран должен ощущаться как “журнал восстановления и нагрузки”. Верхняя часть уже отвечает за быстрое добавление тренировки, а нижняя должна отвечать за ежедневное чтение истории:

- toolbar показывает контекст текущей выборки и быстрые действия;
- timeline-группировка делает историю естественной для спортсмена;
- карточки раскрывают ключевые сигналы без открытия drawer;
- detail drawer становится местом для чтения и редактирования одной сессии без ощущения сырой формы.

## Interaction Model

- Фильтры по активности и toggle `list/grid` сохраняются.
- При выборе тренировки по-прежнему открывается `ViewEditDrawer`.
- Редактирование и удаление в drawer работают как раньше.
- Пустое состояние должно направлять к `Новая тренировка`, а не просто сообщать об отсутствии данных.

## Data And Logic

Используются текущие `workouts`, `filtered`, `selectedWorkout` и существующие поля записи тренировки. Дополнительно на клиенте считаются:

- summary для текущей выборки;
- временные группы для list-view;
- короткие derived labels для отображения даты, длительности и статуса нагрузки.

## Success Criteria

- История тренировок читается быстрее в list-view.
- На узкой ширине список и toolbar не ломаются.
- Drawer просмотра выглядит на одном уровне с новым quick-add drawer.
- Проверка `eslint` и `npm run build` проходит без регрессий.
